# Rose Care Hub

Private internal CRM for M’Gouna Rose. Development only; use fictional data until authentication, authorization and integrations have been tested.

## Development
Install Node.js 22+, run `npm install`, then `npm run dev` after the application scaffold is committed. Run `npm run build` before deployment.

Supabase development project: `fbfgdbeiitmfotydtxgp` (Paris). The private `rose_care` schema contains 18 locked-down tables. Do not expose it or service credentials to browser clients. Implement server-side authorization before accessing real data.
